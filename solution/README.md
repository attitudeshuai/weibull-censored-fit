# 难点与测试对应

## 难点 1：删失件的似然口径

推理轴：领域公式

落在推理路径上的哪里：未失效件只知道撑过停机时刻，它对似然的贡献是生存函数 `ln S(t) = -z^β`，不是密度 `ln f(t)`。把删失件当失效件处理，等于假装它们正好在停机时刻坏了，尺度参数 `η` 与形状参数 `β` 都会明显偏高或偏低。原实现更直接：它根本没看 `failed` 字段。

对应测试：test_censoring_handled_under_heavy_censoring、test_params_match_independent_mle_on_base_dataset

## 难点 2：位置参数 γ 不能取最小观测值

推理轴：数值方法

落在推理路径上的哪里：原实现把 γ 直接设成最小观测时间，于是最短寿命那一条的 `z = t - γ = 0`，`ln z` 直接抛数值错误，整份报告出不来。正确做法是对每个候选 γ 求闭式的 η、再在 (γ, β) 上做二维搜索，并且约束 γ 小于最小失效时间、估出负数时按 0 处理（退化成两参数）。参考解用 γ 粗网格加黄金分割细化，β 在对数尺度上搜。

对应测试：test_two_parameter_limit_when_gamma_near_zero、test_params_match_second_dataset_with_different_parameters

## 难点 3：B 寿命的反解与报告位数

推理轴：业务规则

落在推理路径上的哪里：`B_p = γ + η·(-ln(1-p/100))^(1/β)`，位置参数要加在指数解外面；百分位取输入里的 `b_life_percent`（不一定是 10），参数与寿命的小数位也要按契约给。原实现既漏了 γ，又把百分位写死成 10%。

对应测试：test_b_life_matches_independent_computation、test_report_schema_and_rounding

## 跨运行状态（重复运行与不污染）

同一份记录重复运行，报告逐字节一致（复核可复现）；运行失败时不能覆盖上一次的报告：先写临时文件再原子替换，非法输入以退出码 2 收场且不落文件。对应测试：test_rerun_produces_identical_bytes、test_failed_run_keeps_previous_report。

大样本另有 test_large_sample_recovers_parameters 单独覆盖：300 件、约三成删失时参数要回到真值附近，卡住只能拟合小样本的实现。

## 权重口径

10 条测试：基准参数 0.16、第二组参数 0.13、重删失 0.12、B 寿命 0.10、两参数极限 0.08、非法输入 0.12、输出契约 0.08、重复运行 0.06、失败不覆盖 0.06、大样本 0.09，和为 1。

## 定标依据（自检用）

判分侧另写了一套独立的极大似然求解（先粗网格定位全局峰，再在 (γ, β) 上黄金分割细化），与参考解的搜索路径不同。两者在同一份数据上的解一致到 `loglik` 的 1e-9 量级；β、η 卡 0.5%，γ 卡 3% 或 1 个时间单位（三参数 Weibull 的 γ 在边界附近似然面很平，收紧没有意义）。位置参数取最小观测值的写法会在第一条数据上抛 `math domain error`，实测拿 0。
